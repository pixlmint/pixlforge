# About this website

This custom-built website (powered by nuxt 5 and Vue) serves as my professional
portfolio, however it does not solely rely on custom-written
project writeups. Instead, it is more akin to a custom skin to my self-hosted
[![Forgejo Logo](img/icons/forgejo.svg){style="height: 1rem"} Forgejo Instance](https://git.pixlmint.ch),
enhanced by custom project writeups.

If you are interested in the source code, you can find that
[here](https://git.pixlmint.ch/pixlmint/pixlforge)

## Declaration of AI use
I firmly believe in transparency when it comes to LLM-Generated content,
especially for a page like this, where I want to show-case my work.

### Source Code
The code created for this website is written primarily by me.

The only exceptions:
- Claude was used to figure out the logic for building the commit graphs visible
  on the repository pages
- Claude Design was used to come up with the initial design aesthetic.

### Content
The content you can read on this website (project writeups, the CV and this
about page) is written
by me. If that is not the case, the page will be clearly marked, with details of
how AI was used to write/ improve the text.

### Projects
Most of my projects are written by hand, but I did experiment with vibe coding
and agentic engineering. Any project containing LLM-Generated code will be
marked as such.
